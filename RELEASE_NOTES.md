**Download `DualSpeaker.exe` below (under Assets).** It's a single file, with no Python or installer needed. Windows may warn you the first time because the app isn't signed: click **More info → Run anyway**.

**One-time setup:** install VB-CABLE (free, vb-audio.com/Cable), restart the PC, then set Windows Sound → Output → **CABLE Input**.

**What it does**
- Plays your PC's audio on two speakers at once, even different brands.
- Each speaker has its own volume, mute, on/off, channel (stereo / left / right / mono / swap) and delay.
- **Auto-calibrate:** your laptop mic lines both speakers up in time.
- Drift correction keeps them in sync for hours.
- A simple app window on the PC; the same page works as a phone remote over Wi-Fi.
- Reconnects by itself when a Bluetooth speaker drops.
